# صائد النجوم

لعبة متصفح عربية مستقلة بتصميم فضائي حديث: حرّك السفينة، اجمع النجوم، وتفادَ الشهب. تعمل على الهاتف والكمبيوتر، وتحفظ أفضل نتيجة في المتصفح. تتضمن موسيقى محيطية أصلية مدتها عشر دقائق.

## التشغيل

افتح `index.html` في متصفح حديث. لا تحتاج اللعبة إلى تثبيت أو خادم. اضغط زر الموسيقى لبدء المقطوعة؛ يسمح المتصفح بتشغيل الصوت بعد تفاعل المستخدم.

## التحكم

- الهاتف واللمس: اسحب السفينة داخل ساحة اللعب.
- الكمبيوتر: استخدم السهمين أو `A` و`D`.
- مفتاح المسافة يبدأ الجولة أو يستأنفها، و`Escape` يوقف اللعب مؤقتًا.

النجمة تزيد نقطة، والاصطدام بالشهاب ينقص قلبًا. يمكنك تفويت النجوم دون خسارة قلب. تزداد سرعة اللعبة كلما ارتفعت النتيجة.

## حجم المشروع والموسيقى

ملف الموسيقى `assets/star-catcher-ost.wav` يجعل حجم المشروع أكبر من 100 ميغابايت. أُنشئ باستخدام Python القياسي دون مكتبات أو ملفات صوتية خارجية. لإعادة توليده شغّل `python3 tools/generate_soundtrack.py`.
